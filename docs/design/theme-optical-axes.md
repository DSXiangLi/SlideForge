# 主题光学轴扩展：六轴盘点 × F 系新主题 × C3/E5 升级

> 状态：已实施（2026-10-07） · 触发：用户观察"当前主题几乎都在用线+颜色构建视觉，阴影/光线/透明度/容器多样性极少" · 方法：全库手法量化盘点 + dashi/open-design/guizang 等外部项目手法解剖
> 本文是决策与规格记录；验收证据见 `docs/test_acceptance/theme-optical-axes.md`（渲染截图前后对比）。

## 一、盘点结论：四根手法轴整格空缺

对 themes/index.md 21 个主题全量精读 + 正则计数（2026-10-07）：

| 维度 | 现状 |
|---|---|
| box-shadow | 全库 10 处 / 6 主题；**17/21 主题明文"禁阴影"**；多层柔和弥散阴影 = 0；浮层卡仅 D1 一家 |
| text-shadow / 发光字 | 主题 CSS 零落码（骨架 `.tt-glow`/`.tt-shadow` 词汇空转） |
| backdrop-filter 毛玻璃 | 绝对零，且 8+ 主题明文禁止 |
| 彩色→彩色平滑渐变 | 绝对零（渐变只做角落洗色 token→transparent 与硬断点图案） |
| filter:blur 光斑 / 暗角 | 零 |
| 圆角容器 | 17/21 主题直角/微直角；圆角仅 D1、E6 |

差异化实际只靠四根轴：颜色 + 字体 + 线汇 + 平涂色块。C3 是最大名实落差：世界参考写着"磷光"，没有一个像素在发光。

## 二、第一性原理：幻灯片画面的六根视觉轴

一张幻灯片 = 基底 × 容器 × 分隔 × 纵深 × 光线 × 材质，外加横切轴"排版即装饰"：

1. **基底纵深**：flat → 氛围渐变 → 光斑 → 噪点 → 网格 → 暗角（"脱离白板感"的最高杠杆）
2. **容器形态**：无框 → 线框 → 色块 → 浮层（阴影托起）→ 玻璃叠层 → 异形
3. **分隔结构**：线 / 明度差 / 留白 / 光学边界（本库唯一厚实的轴）
4. **纵深 elevation**：多层柔和投影（品牌色染影）/ 硬偏移影 / 以影代边 / 内陷影
5. **光线**：辉光 → rim-glow 内发光 → 发光字 → 模糊光晕 → 旋转光环（纪律：单色系全页复用）
6. **材质截面**：纸 / 金属 / 玻璃 / 霓虹 / 荧光（本库材质光谱只有"纸"一端）

关键洞察（dashi 解剖佐证）：高级感 ≠ 手法总数——dashi 12 主题里 5 个零阴影照样高级，因为每个主题在 1–2 根轴上**体系化**（rim-glow 五层、玻璃六件套、glow 单色复用）。本库的问题是四根轴整格空缺，21 个主题挤在同一低维象限。

## 三、决策：Both——新建立轴主题 + 升级名实不符的旧主题

**不做什么**：不改 B1/C4/A1（薄是编辑部扁平立场，薄即正确）；不给既有主题无差别加阴影（8+ 主题明文禁玻璃/阴影是立场，改之即毁）。

### 3.1 新建 F 系「光与纵深」三主题（21 → 24）

| id | 名称 | 立的轴 | 世界参考 | unforgettable | focus |
|---|---|---|---|---|---|
| f1 | 浮光玻璃 | 容器(玻璃) + 基底(光斑) | macOS/iOS 毛玻璃材质体系 | 玻璃卡浮在彩色光斑上，光透过玻璃漫上来 | G3 + G4 |
| f2 | 霓虹夜行 | 光线(发光体系) + 容器 | 夜街霓虹灯管招牌 | rim-glow 灯管卡：容器边缘一圈内发光像灯管点亮 | G4 + G9 |
| f3 | 暮色长镜 | 基底(渐变+暗角) + 色彩 | 黄金时刻电影摄影与史诗片海报 | 地平线色带：仪式页底部日落渐变带，页面定格为一帧 | G3 + G1 |

- **G3 新增质感类型 `aura`**（氛围光：多团光斑 / 渐变 + 暗角），枚举扩为 flat/glow/grain/paper/hand-drawn/aura（sync-themes.mjs 与 theme-schema.md §4 同步）。
- f1 `--texture-scope: all`（玻璃需要光斑才有物可透，正文页默认 texture-on）；f2 glow/cover；f3 aura/cover。
- 首发技术负债清零：text-shadow（f2 `.mt-neo-sign`）、backdrop-filter（f1 `.mt-gls-card`）、filter:blur 光斑（f1 `.mt-gls-blob`）、多层柔和投影（f1 G4 三档）、彩色平滑渐变 + background-clip:text 渐变字（f3 `.mt-dsk-grad`）全部入库。
- bake_brief 本批暂不写（非试点主题合法缺省），铺量批次再补。

### 3.2 旧主题升级（只动"名实不符"，不动"立场之薄"）

- **C3 终端绿**：兑现磷光——G4 阴影立场从"无"改为"磷光晕散体系"（文字/描边允许同色低透明辉光，仍禁承托投影）；G9 新增 `.mt-term-glow`（关键字磷光晕散），`.mt-term-box`/`.mt-term-caret` 补低透明辉光。L1/L3 不动（c1/e11 的分化声明不受影响）。
- **E5 构成主义**：兑现石印世界——G3 scope cover→all（石印颗粒全页轻铺，油墨世界的纸都有肌理）；G9 新增 `.mt-con-wedge`（楔形块，Lissitzky 红楔词汇）与 `.mt-con-diag` 双印变体（套印错位感）。

### 3.3 手法纪律条款（随新手法入库，防"加手法=加噪声"）

1. 每页 1–2 根主轴手法，禁跨轴堆砌；
2. 发光严格单色（accent）——第二个发光色出现即事故（f2 G9 明禁）；
3. 阴影必带色相（ink/accent 色系 color-mix 派生，禁中性纯灰黑重影）；
4. 玻璃六件齐上（半透明渐变底 + blur≥14px + saturate≥140% + 半透亮边 + inset 顶高光 + 柔和外影），缺一像蒙灰；玻璃下只许光斑或纸面，禁玻璃叠玻璃；
5. 这些条款写进各主题 G4/G9 禁忌，不进全局——A–E 系的扁平立场继续合法。

## 五、修订记录（2026-10-08，用户验收后）

1. **F2/C3 区分度重构**：用户目检认为 F2（电青）与 C3（磷光绿）观感过近。修订：F2 基底 accent 电青→**霓紫**（全库无紫色系 accent，色相距离最大化）；世界参考锐化为"雨后夜街"——新增母题 `.mt-neo-refl`（雨后倒影：内容副本 scaleY(-1) + 渐隐 mask + blur(1px)）；签名动效升级为 **flicker-in 通电点亮**（skeleton v7.6 新增 enter 族 recipe，inview 一次性 steps 抖动后常亮，主题限定发光体系主题）；变体组改为 霓紫（基底）/电青/品红（撤掉与 C3 相邻的荧绿）。像素探针复核：f2 页紫调 1.4–1.5%、电青/绿残留 0.00%、倒影区淡紫渐隐成立。
2. **motion 升级评估结论**：light 族（sweep/border-beam/god-rays/leak/spotlight）与 amb 族（glow/drift/pulse）已覆盖 F1/F3——F1 用 rise-in/blur-in + amb-drift 光斑即可，F3 长镜纪律要求不动；唯一真实缺口是霓虹世界的"通电点亮"签名，故只补 flicker-in 一款（motion.md 8 族 46 recipe），不动八族结构。
3. **法则落纸**：components.md §12 新增硬规则 6「光学容器」——玻璃叠层/发光边缘/亮度阶梯薄面三型豁免四档明度平涂与填充描边互斥，受四纪律约束（主题显式声明、发光单色、阴影带色相、每页 1–2 根主轴）。
4. **PPTX 双轨适配实证**（theme-sampler 24 页双轨导出 /tmp 副本，274.9s exit 0）：保真轨 f1/f2/f3 保真分 95.2/95.2/99.1——backdrop-filter 玻璃、发光、渐变字、暗角在 printToPDF→SVG 链路全部存活（发光轻微衰减）；可编辑轨文本零烙图（text_coverage=1.0），视觉层按"文本永不烙图、视觉层记 uncovered"既定契约降级（f1 玻璃卡→L5 无字烙图、f2 光晕丢失仅留原生紫字+烙图倒影、f3 近乎无损）。结论：**暮色长镜与 PPTX 原生模型天然兼容；玻璃/霓虹以保真轨为交付轨**。逐页清单见 `../test_acceptance/theme-optical-axes.md`。
5. **skeleton 特异性 bug 修复**：flicker-in 的 reduced-motion 关停规则原写法特异性 (0,2,0) 输给 in-view 触发规则 (0,4,0)（reduce 下动画照播），已改为同特异性后置写法；gallery/sampler 内嵌骨架同步此写法。
