## 结果

### 信息图页 data-flow → accept（划算）

- OCR exact 14/18：两处标点级（0.97）、图例 mono 句缺头、焦点句"5% 流量先试"读作"59"（数字疑点，目检终裁）。
- 结构专项：四节点 事件采集→清洗建模→灰度生效→全量复盘 全部在场且顺序正确（OCR 位置 78<88<98<107）。
- 四角复扫无 logo/chrome。harmony 零告警。

### 对比页 split-compare → accept（划算）

- OCR exact 14/16：三对数值全在（3.5 人/4 小时/27 起 vs 0.5 人/40 秒/2 起），VS/BEFORE/AFTER 标记在场（BEFORE 宽字距致 OCR 拆分，非错误）。
- 疑点：右侧定性句尾部疑复制左句（"规则进系统，响应进秒级" → 最佳匹配"规则进系统响应靠运气"），目检终裁。
- 四角复扫干净。harmony 零告警。

### 图表页 profit-waterfall → reject（不划算，纪律化）

数据失真三线齐发：

1. **副题数字错**："从 120 到 194" 读作 "从120到184"；
2. **减号丢失**：−38 → 38、−25 → 25（符号语义反转）；
3. **柱高比例失真**：像素测量（实心行 ≥70% 列宽分割柱簇）检出 5/7 柱（两根浅色减益柱未过掩码），检出柱归一估值 [136.2 / 75.3 / 31.2 / 12.2 / 194] 对期望 [120 / 86 / 42 / 25 或 9 / 194]——误差 10–26%。

四角复扫干净。harmony 零告警。

## 布局重构实验（v5 restructure 授权，同日下午）

- 起因：用户新方向——生图不只是视觉升维，还包括**布局层面优化**：中低密度平铺文本页能否经烙入重构为结构化信息图。v4 蓝图纪律恰约束布局重构，故编译器加 `restructure` 选项（v5）：plan.json 页级 `restructure:true` → Layout 节输出重构授权段（替代一般构图授权；三硬约束烧死：文字逐字/信息层级/配色基调）。m_bake_check ③h/③i 双分支断言。
- 实验页：`demos/imagegen-v2-restructure/`（B1，skeleton v7.6）`flat-process`——四段平铺散文（企业上云迁移四阶段，395 字符，无任何结构化组件）。
- 调用：1 次（flare/high/**n=2** 双候选，专项累计 **13/12 超预算 1 次——用户"请尝试"明确授权**，如实记录）。
- **结果：重构成立（双候选）**。判定证据：OCR 框 36–40 个且 >60% 宽度的段落框为 0（段落形态消失）；编号系统 01–04 + 提炼阶段名（源文无"评估与盘点"等词，模型自行提炼）+ 15–17 条长连线结构件；字符级覆盖 99–100%（无缺句；行级 exact 0/5 为跨框碎裂的指标失真）。疑点：析/阈/迁 单字为 OCR 近似字混淆高发区，目检终裁。cand0 左下角一处乱码框（疑纹理误读）。
- 产物：baked-flat-process-{0,1}.png、anchor、prompts/flat-process.md、rubric-restructure.json（七维含"布局重构"维）、compare-restructure.png（HTML 平铺页 / 候选 0 / 候选 1 三联）。
- 纪律回灌：bake-prompts.md §6.5——适用三条件（中低密度 ≤500 字符 / 平铺文本无结构件 / 内容有关系类型）+ 伪重构失败模式（段落加边框不算重构，加强负向措辞重 roll 一次不过即回退）。第 2 次预算内调用未花（第一次即成立，flat-compare 页留作后续验证位）。

## G 组：图表页数据强锚定（profit-waterfall v2，同日晚）

- 起因：用户修正——图表页不是禁烙，验证"数据强锚定指令"能否压住失真。
- 指令：Layout 逐字写出七点数值 + 桥接位置 + 百分比比例（120:86:42:38:25:9:194，以 194 为满高逐柱给 %）+ Constraints 数据条款。1 次调用 → `baked-profit-waterfall-v2.png` + `compare-chart-v2.png` + `rubric-chart-v2.json`。
- **结果：文字层收敛、几何层不收敛——维持禁烙纪律**。数字 120/+86/+42/+9/194 全对、副题"从 120 到 194"修复（上轮 184）、减号在场（ASCII "-"，上轮的"丢失"部分系 Unicode − vs ASCII - 字符集假象）；但柱高误差仍 +18%/−31%/+8%/+20%（5/7 柱检出，浅色减益柱未过掩码为方法局限）——超 10% 阈。
- 纪律措辞最终版：§0 第 3 条维持"定量图表页禁整页烙入"，§6.7 记录强锚定写法与"文字可锚定、几何不可锚定"的证据边界。
- 调用：H+G 各 1 次（共 2 次，预算内）；专项累计 **15 次**（授权轨迹：10→12→14，本轮 2 次）。
