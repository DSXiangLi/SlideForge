## 一、方法论的根问题（最该先正视）

1. **视觉判断缺失**：执行模型无法查看渲染图，所有「美感 / 整齐度 / 是否顺眼」的判断依赖量化指标 + 用户目视。结果是视觉层面反复返工（至少 8 轮打回）。
2. **优化缺少总纲**：每轮只在一个维度上打转（卡片样式 → 布局秩序 → 构图骨架 → 明度签名 → 恢复特色），从未先回答「每套主题到底该是什么样子」这个总纲问题，属于「打地鼠式」修补。
3. **度量信号与设计意图冲突**：结构指纹内置「极性归一」（暗底页反相），导致刻意做的「明度反转」（E7 深块 vs F1 深底）在度量上被抹平，测出的「相关」与视觉意图错位。

## 五、差异化维度的根本矛盾

22. 「方向」维度太窄（水平 / 垂直 / 对角 / 中心几种），30 套主题光靠方向必然撞车。
23. 明度反转被指纹极性归一抹平，无法作为可度量的差异载体。
24. 「要特色（糖果色 / 深墨 / 玻璃大块做焦点）」与「灰度去色可分」客观冲突——都用大色块做焦点，灰度结构就趋同，hero 页尤其明显。
25. 「PPT 整齐（标题一行、网格对齐）」与「灰度去色可分」之间也是张力——越整齐越趋同。
