# 1009 · 多色主题设计复盘：根因分析与修复路线

> 触发：用户对 G 系与 E1/E4 升级的四条批评——① 翡翠年鉴满铺绿难看，大面积用色缺规范；② 孟菲斯应有更多配色（马卡龙等）；③ 包豪斯升级浮在表面（加了颜色没有深度，核心在几何构成）；④ 孔版同病，且这批主题整体被 guizang 杂志框架框住，差异点不明显；配色"区域平均、不够高级"。本文是根因分析与修复路线，实施记录续文末。

## 一、根因分析（为什么这轮不达标）

### 根因 1：没有"面积×彩度"用色规范

我们把 accent 级高彩度色直接拿去满铺（翡翠 #3CD896 100% 铺底）。大面积用色和小面积点色遵守不同的物理：彩度越高允许的面积越小。frontend-slides 的高彩满铺先例（emerald-editorial、pin-and-paper）其实都偏浊/偏深，且墨极深压住；dashi t08 酸黄满铺实测彩色面积排序是 墨>纸>蓝>黄——"满铺"主题里主导色也未必是彩色本身。**规范缺失**让选色凭直觉，直觉在大面积上必翻车。

### 根因 2：把"加色"当成了"加风格"

包豪斯的深度不在红黄蓝，在**几何作为结构**：粗结构线划格、基本形与文字的真实穿插（形穿字下、色面即容器）、不对称平衡的张力。我们把三色贴成装饰件，形是漂浮的贴纸，所以"浮在表面"。孔版同理：riso 的丰富来自**大面积双版叠印**（色面错版叠出第三色、网目调渐变），不是标题后一条错位贴纸。教训：主题差异化的主轴在该世界的**结构手法**，色彩只是它的染料。

### 根因 3：版式 DNA 单一（guizang 框架的路径依赖）

全库样张共享"刊头+标题+内容带"的编辑部版式骨架，主题差异只落在 token/母题层，所以一眼望去"差异点都不明显"。frontend-slides 的主题在**布局结构层**就分叉（满铺色域、分屏、海报网格、便签撒布）。主题的七层里 L7 构图倾向我们有声明但没在样张层兑现——样张自己就没有按主题构图倾向排布。

### 根因 4：配色"区域平均"

frontend-slides 的原话：主导色 + 锐利点题色胜过温吞均分（Dominant colors with sharp accents outperform timid, evenly-distributed palettes）。这轮配色在多主题上犯了均分病（底/墨/accent 各管一摊、明度差接近），缺"90% 冷暗 + 5% 篝火"式的张力配比。

## 二、修复路线

1. **大面积用色规范入正典**（themes.md Schema 节）：面积-彩度反比律 + 深/浅/浊三窗口 + 主客配比律（详见 themes.md「大面积用色规范」）。
2. **G1 翡翠年鉴重配色**：亮薄荷绿满铺 → **深翡翠绒面**（深调绿底 + 奶油墨 + 金箔点）——大面积色走深调窗口，绿色相保留但降到绒面明度；薄荷晨场变体保留为浅调窗口对照。
3. **E4 包豪斯深度修复**：基本形从装饰件升级为**结构件**——新增粗结构条 `.mt-bau-bar`、四分之一圆 `.mt-bau-quarter`，形色对应不变；页面级规则：基本形必须参与构图（穿压文字下层/作色面容器/破网格），禁孤立漂浮。样张页按"构成先行"重排。
4. **E1 孔版深度修复**：新增 `.mt-ris-field` 大面积双版套印色面（错位量随面积放大到 4px，multiply 叠第三色），套印从"标题垫"升级为"色面容器工艺"。
5. **E6 马卡龙变体**：palette 四色换马卡龙档（粉樱/奶油黄/ baby 蓝/薄荷绿，全浅调窗口）。
6. **版式层**：本批先在 proving deck 各主题页强制执行 L7 构图倾向（g1 年鉴网格/g4 出血裂屏/e4 构成格等），样张页重排；全库版式 DNA 分叉是更大工程，记入 roadmap 后续评估。

## 五、第三轮（用户二次点评后）

用户判定：翡翠脱颖而出、孟菲斯不错；包豪斯"对了一半"（有几何但只做装饰，小气、缺空间与层次感）；孔版仍不伦不类（深色容器压正文）；配色对比 frontend-slides 仍无"眼前一亮"。

- **E4 尺度纪律**：基本形短边 ≥ 画幅短边 1/5（≥216px），小形即贴纸禁止；色面容器合法面积 1/4–1/2 页；出血合法且推荐；竖向空间必须被形/条贯穿或切断。proving/sampler/gallery 的 e4 页全部按建筑尺度重排（红色面容器占页 21–28% 承载真实数据、quarter 480px 出血、bar 贯穿）。探针：三色俱在、最大色面 ≥1/5 页 ✓。
- **E1 对比度铁律**：riso 世界不存在深色容器——ink/ink-tint 深底容器明禁；文字永远落纸面；套印色面只压 ≥56px 粗黑海报标题。proving/sampler/gallery 的 e1 页深色容器清零（探针：暗像素仅文字笔画级 0.82–3.4%）。
- **G5 三色旬刊入库**（29 主题）：封闭三色零中性（胭脂 #F2B6C6 / 黄油 #F2D86A / 勃艮第 #7A1F35）——frontend-slides editorial-tri-tone 的回灌，全库第一种"无黑无白无灰"结构；三色反转配对容器（酒红底黄油字↔黄油底酒红字）、三色带/刊号签/双线刊框母题；变体 抹茶三色/海盐三色。探针：三色俱在、纯黑纯白像素 0.0000%。
- **T34 扩为 8 主题 × 8 页型 = 64 页**；新增 g5-cover 多色实证（胭脂与酒红同色相靠明度分家，故该页改用 ΔRGB token 近邻计数）；check-render proving 64/64、sampler 29/29 ALL PASS、gallery 零新增（61 页）。
- **README 精选 12 再换血**：g2/e10 下，g5/e4 上（c3/e1/e2/c1/e7/e6/g1/g5/e4/f1/f2/f3）。
- **check-render headless 测量盲区**（子代理实测发现，记入 learnings）：程序化滚动在 headless+content-visibility 下可疑失效，远屏页 mask-lines 初始位移误报重叠——修法备查（测量前强制 visible + reduced-motion 终态口径）。

## 六、用户最终验收结论（2026-10-08，四轮迭代后）

**通过的（已确认入库，进入 README theme gallery）**：
- G1 翡翠年鉴（深翡翠绒面 × 奶油墨 × 金箔单点）——深调大面积用色规范的首个成功样本
- E6 孟菲斯（糖果四色 palette 轮转 + 马卡龙变体）——多色轮转制成立
- G4 靛墨黄页（靛蓝墨 × 太阳黄互补对撞 + 余烬橙单点）——互补双色结构成立
- G2 腮红荧光笔（粉彩底 × 四支荧光笔预配对 on-color）——荧光笔标注制成立

**未通过的（结论记录，不再优化，留后续重做）**：
- E1 孔版印刷——套印色面工艺始终未达到 riso 海报的视觉冲击力，配色奇怪；多轮重排（双版套印/对比度铁律/副辊内缩）均未通过目检
- E4 包豪斯——几何构图依旧缺乏美感，尺度纪律与色面即空间仍未解决设计感问题；包豪斯的核心美学需要更深的构成研究，非配色与尺度纪律可解决
- G3 陶土印刷——零特色，砖红彩色墨结构未传递出预期风格
- G5 三色旬刊——本轮未获用户明确通过/未通过，但用户列出的通过名单未含 g5；保守记为未明确通过（README 暂不收入，代码保留入库不撤）

**教训（记入 learnings）**：配色即风格需要"色板本身即辨识度"的审美判断，非结构规范可替代；E1/E4 的多轮修复证明——当主题的核心美学（riso 的印刷事故美/包豪斯的构成张力）没有在第一版抓住时，后续的规范补丁只能让它在"合规"与"有特色"之间反复横跳，不会收敛到"有美感"。
