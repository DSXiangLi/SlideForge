# 1008 · 多色彩主题体系：分析实录与优化路线

> 触发：用户验收 F 系后指出——对比 dashi，我们的 deck 倾向单调色（容器颜色单一、字体颜色单一）；多色不止在图表/类目，还在容器层（彩带/容器面色/彩色阴影）、装饰层、字体层、风格层；且不止孟菲斯适合多色；frontend-slides 的独特**配色组合**本身就传递风格。设计文档 `docs/design/theme-multi-hue.md`。

## 一、问题定位：单色是结构使然，不是审美选择

四个系统性根因：① G1 只有 6 token 单 accent，没有第二个彩色的位置；② 图表系列色全部从单 accent color-mix 派生（同色相深浅阶梯，无对比色）；③ 容器四档明度只有一个彩色槽位且 accent 档单焦点；④ accent 预算 ≤10% 压死彩色面积。这套纪律造就了编辑部高级感，副作用是全员"素"。

## 二、调研结论（frontend-slides / dashi / html-ppt-skill 解剖）

**多色不是"accent 变多"，是不同的色彩组织模式**，每种模式自带封闭色板 + 分配规则 + 防花纪律：

| 组织模式 | 代表 | 法则 |
|---|---|---|
| 封闭三色制 | editorial-tri-tone | 全系统仅 3 个 hex，变量名全是语义别名；"禁第四色"即设计前提 |
| 色相轮转制 | sakura-chroma / dashi t12 | 固定顺序轮转，"index→colour 是 API 契约不是随机" |
| 粉彩贴纸制 | daisy-days / dashi t08 | 8 粉彩 + 唯一高饱和注意力色；墨色骨架托底（边框/阴影永远墨色） |
| 荧光笔配对制 | dashi t12 | 每支荧光色预配对 on-color，杜绝对比度事故 |
| 语义层级制 | midcentury / dashi t04 | 三色各管一级文字；类目→颜色跨页稳定 |
| 全谱光谱制 | dashi t05 | 色相环等距 7 色只喂图表系列 |

**配色即风格**（14 个高辨识度色板解剖）：色彩结构比色数更重要——彩色墨（long-table 砖红墨/cobalt 钴蓝墨）、彩色满铺底（emerald 绿/pin-and-paper 黄）、互补对撞（黄×靛、蓝×橙）、粉彩底×荧光标注、隐形色（红只做阴影层）。

**我们的空缺带**（24 主题实测色相分布）：红域/蓝域过饱和（各 5+），绿身份、紫身份（F2 霓紫已部分补上）、高明度粉彩底、彩色墨、互补双色结构五个带全空。

## 三、核心决策：多色 = 主题级世界属性，不是全局开关

多色模式各自绑定容器造型/母题/防花纪律，天然满足"两两七层 diff≥3"；全局开关只动 L1 必然违和。但**单 accent 锚点不丢**：多色主题保留 accent 锚点管强调语义，palette 序列管类目/图表/轮转——accent 预算升级为"注意力色预算"。

## 四、优化路线（五个阶段）

1. **Schema 扩展**：G1 可选多色字段组——`--accent-2/--accent-3`（语义锚点）+ `--palette-N`（类目轮转，固定顺序=契约）+ `--hl-N`（荧光笔，每色强制预配对 `--hl-N-on`）+ 图表 `--chart-series-N` 显式声明开口（缺省回落 color-mix 推导）；校验器强制多色主题的 on-color 配对与封闭色板声明；components.md §12 增"多色容器纪律"（彩色容器/彩带只许来自主题 palette 声明；彩色阴影色相规则）。
2. **旧主题升级（名实不符兑现）**：E4 包豪斯→三原色（红黄蓝本质）、E1 孔版→多色套印（riso 本质是多版叠印）、E6 孟菲斯→多彩碎形；C2 暗夜植物园补绿变体（名不副实的轻量修复）。
3. **G 系「色彩结构」新主题 ×4**：G1 翡翠年鉴（高饱和绿满铺底×深蓝墨×奶油喘息区，填绿身份空缺）、G2 腮红荧光笔（粉彩底×四支荧光笔预配对，多色只以标注形态存在）、G3 陶土印刷（砖红彩色墨×奶油三档，零黑零灰）、G4 靛墨黄页（靛蓝墨×太阳黄互补对撞，双年展海报）。
4. **验收资产**：`tests/decks/theme-proving/`——每个新/升级主题一组 7 页型（封面/目录/低密度/高密度/≥2 信息图类型/≥2 图表类型），harness 新增 T34 结构性校验 + check-render + 截图证据。
5. **收尾**：全量回归 + README + 文档同步。

## 五、防花纪律（随主题 G1 立场走，校验器可查）

封闭色板禁令（色数是设计前提）/ palette 顺序固定 / on-color 预配对 / 墨色骨架托底（结构线与阴影的色相由主题显式声明）/ 注意力色预算（多色之上仍只有一个高饱和焦点）。
