## 3. 四套主题的详细优化方案（SOP Step 1–2）

### 3.1 通用设计判断（勿重算）

1. `--t-display` 按主题性格以 `typography.md` §1 封面 120–160px 为锚定档，**不**用 ×19.2 盲换算旧 cqw；`--t-body:35px` 是唯一忠实换算值；`--t-heading` **不覆盖**（保留 64px，维持标题:正文 ≥1.8:1）。
2. 四套 `signature_operator` 的 silhouette 必须**彼此分开，且与已升级 4 套分开**：
   B1 12 栏网格 / C3 终端时间流 / E5 −12° 力带 / H1 竖排题跋 vs
   **E6 之字折线路径 / G2 左正文层+右索引脊 / E7 横向三层套印 / F1 斜向深度栈**。
3. 签名形状必须装信息（G10 草案 §1 纪律 2）：形状 CSS 带 `data-editable-skip`，内部文字仍是 `data-editable` 叶子。
4. `invariants` 每条可在渲染 DOM/像素上测，且至少 1 条几何方向性。
5. **设计层规避弱读**：四套 G10 `rule` 一律写「正文层 opacity = 1，禁对文字降透明度」；F1 尤其禁止玻璃层叠玻璃与光斑进入文本层祖先链（backdrop-filter 嵌套会糊字）。这是从主题结构上根治，不加后拦截门禁。

### 3.2 E6 孟菲斯 · 之字路径积木

| 字段 | 内容 |
|---|---|
| doctrine | 反叛的秩序；信息不是被摆进格子，而是被一串有重量的积木沿路径推着走 |
| signature_operator | 把每条信息编译成一块 3px 墨线粗描边的「积木」，用一条之字折线把它们串成单向路径：积木沿路径逐块吸附、宽度随信息权重阶梯放大、填充按 palette 固定顺序轮转；三项数字重排为沿路径递进的三块台阶（非横排等权格），唯一焦点积木带 8px 硬偏移影；之字线是路径本身而非分隔装饰 |
| silhouette | 之字折线主路径（45°/135° 转折）；圆角矩形积木；起点左下、终点右上；重心沿对角带；右下 ≥15% 留白 |
| info_grammar | cover 单块超大积木吞标题＋之字线自左下引入 / claim 论点独占焦点积木（最大＋硬偏移影），说明在第二块 / analysis 3–5 块沿路径阶梯、palette 轮转 / data 三项数字 → 三块逐级放大台阶，末块承载结论短句 |
| invariants | ① 之字路径 1 条，转折角 ∈{45°,135°}，长度 ≥60% 画幅对角；② 积木宽沿路径单调不减，焦点块面积 ≥其余 1.4×；③ 硬偏移影单页 ≤1、8px 零模糊；④ 横排等权三格容器数 = 0；⑤ 彩纸屑在 DOM 上是积木的兄弟节点，不进积木内部 |
| forbidden_defaults | 横向等权三格 KPI / 卡片墙成阵 / 居中 hero / hairline 分区 / 无路径撒布式彩纸屑 / 玻璃拟态 / 弥散软影 |
| dna_events | cover 强 · claim 强 · analysis 中 · data 强 · toc 中 · closing 强 |
| 令牌 | `--t-display:132px`（极粗 800 承载积木压强）、`--t-body:35px`，heading 继承 64 |
| G9 改造 | 新增 `.mt-mem-path`（之字路径结构件）、`.mt-mem-block`（积木，签名结构件，内部文字可编辑）、`.mt-mem-step`（台阶）；把 `.mt-mem-confetti` 的 `inset:0` 全页覆盖改为受控定位，避免压字；`:root` 注入令牌 |
| **DOM 结构测试** | 删掉算子 → 页面回到「标题 + 两段正文 + 横排三格 KPI」，之字路径、积木分组、阶梯宽度、palette 轮转顺序、台阶全部消失；元素数量/分组/顺序/位置**都变** → PASS |

### 3.5 F1 浮光玻璃 · 斜向玻璃深度栈

| 字段 | 内容 |
|---|---|
| doctrine | 层级不是靠线划出来的，是靠「离光源多远」量出来的 |
| signature_operator | 把内容编译成一条由近到远的「玻璃深度栈」：每类信息是一层玻璃，按信息优先级分配离光源的距离（近/中/远景），层数 3–4 且每层有固定 z 深度与不透明度档；近景承载标题与结论数字，中景承载说明，远景只容图注；层与层不并列，而是沿一条左下→右上的斜向深度轴逐级错位叠压；三项 KPI 重排为沿深度轴逐级后退的三枚玻璃 chip（非横排三格） |
| silhouette | ≈12° 斜向深度轴 + 3–4 层圆角玻璃面逐级后退；重心由左下推向右上；左上长留白 |
| info_grammar | cover 单块近景玻璃吞标题＋满幅光斑（封面特权）/ claim 近景主张句＋中景一行说明，沿轴左右错位 / analysis 3–4 层按信息优先级排序，同圆角同 gap 但**不同 z 档**、不并列成阵 / data 三项数字 → 三枚沿轴逐级后退的 chip，末枚为焦点 |
| invariants | ① 玻璃层数 3–4，各层 z / 不透明度档互不相同；② 相邻层中心沿深度轴位移 ≥120px，主轴 12°±4°；③ 无祖先-后代 `backdrop-filter` 嵌套（玻璃不叠玻璃）；④ 光斑层是文本层的兄弟节点，不进入任何文本节点的祖先链；⑤ 横排等权三格容器数 = 0 |
