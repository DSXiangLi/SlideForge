## 0. 一句话结论（升维后看到的问题本质）

之前所有工作——从 rev3「秩序规则」到 rev6「全要素体检」——**都停在「卡片/元素级」**：
`signature_operator` 定义的是「积木 / 玻璃层 / 套印版 / 行栏」这些**零件怎么造**，
却从来没有定义**这些零件在整页上怎么装配**。

于是出现：**零件有特色，但没有「总装图」。**
卡片占比（占页面多少）、卡片间距（沟槽/边距）、卡片重叠（谁压谁、压多少）——
这三样「关系」从没有被一条页面级总纲统领，全部靠每页临时拍坐标。

这正是你点的两个核心问题的共同根因。

## 1. 量化证据（质心 / 象限密度 / 覆盖率）

画布 1920×1080，光学中心 (960, 540)。对 4 套 full 页文本质心实测：

| 主题 | 内容质心 | 偏离中心 | 右半区密度 | 覆盖率 | 判读 |
|---|---|---|---|---|---|
| **E6** | (956, 487) | (−4, −53) 尚可 | TR 53% | 78% | full 页尚可，**但 6 页型卡片散乱**（见 §2.1） |
| **G2** | (886, 509) | (−74, −31) 略左 | TR 14% | 79% | 两栏可成立，缺栏宽/边距系统 |
| **E7** | (847, 587) | (−113, +47) 左+下 | **TR 2%** | 83% | **左重右空** + 三层全宽横带雷同 |
| **F1** | (740, 553) | **(−220, +13)** | **TR 0 / BR 2%** | 78% | **左柱堆叠，右 2/3 死区，最重层在底 → 左下失衡** |

三个铁证：
1. **F1 质心 x=740，比中心左偏 220px**，右半区内容密度 ≈ 0% —— 不是「左下角重」的感觉问题，是**结构性失衡**：三个玻璃层全左缘 x=120 起、垂直堆叠，右边 2/3 几乎空白，且最不透明、最大的一层压在底部。
2. **E7 质心左偏 113px、右上象限密度仅 2%** —— 文字全部左锚（`left:40px`），右半页只有「版次」小字；且三块 plate 是**三条全宽横带平行堆叠**，版差只有 48px（几乎不可见），所以「层次齐了、但没有任何构图张力」。
3. **覆盖率 78–83%** —— SOTA 扁平/玻璃风留白普遍 40–50%，四套都「填太满」，负空间被挤压，专业感打折扣。

## 2. 缺的核心平面设计原则（按重要性）

版式设计的经典四原则 CRAP（对比/重复/对齐/亲密性）里，对比、重复、对齐我已做了，**真正缺的是更上层的「构图层」三件套**：

| 缺失原则 | 现状 | 后果 |
|---|---|---|
| **① 网格系统（Grid）** | 坐标 140/120/170/1340/820/540/980… 各自为政，无统一模数、边距、沟槽 | 卡片间距「零散不一致」，无法被一条规则复述 |
| **② 视觉平衡（Balance）** | F1/E7 左重右空，重心不落光学中心/三分点/对角线 | 页面失衡、右半页浪费 |
| **③ 负空间（Whitespace）** | 覆盖率 78–83%，几乎铺满 | 堵、无呼吸感，不像 SOTA 演示 |
| **④ 视觉动线/分区（Flow & Zoning）** | 无「标题区/正文区/数据区/页脚区」的固定占比与走向 | 视线没有引导，读者不知道先看哪 |

你点到的「左总览右分点 / 中心轴 / 对角线」——**正是这四样里最核心的「构图骨架」**，即一个页面该用哪种空间结构去摆放信息。这是当前 G10 契约完全没有的一层。

## 3. 每套主题的构图骨架方案（专业命名）

关键转变：**差异不该来自「块乱摆」，也不该来自「每套各拍一套坐标」，而应来自「每套选一种经典构图骨架」**。骨架不同 = 一眼可辨，且每套骨架内部都有教科书级的秩序。

| 主题 | 构图骨架（专业命名） | 具体规则 |
|---|---|---|
| **E6 孟菲斯** | **模块化网格 + Z 型动线** | 12 列网格，统一边距 120 / 沟槽 40；标题锚块占上 1/3（全宽或 2/3）；正文两栏在网格线上；KPI 三块沿底部网格线等距。孟菲斯的「活泼」来自**色块/波点/之字背景装饰 + 5–8px 微错位**，**卡片本身必须吸附网格**——「之字」降级为背景装饰，不再当卡片摆放规则 |
| **G2 荧光笔** | **非对称两栏（正文 : 批注 ≈ 60 : 32 : 8）** | 左正文 + 右索引脊，栏宽比例固定、左右边距统一 120、行距留白；「左总览右分点」的教科书式落地 |
| **E7 浮世绘** | **对角线构图（前景大物 → 远景）** | 弃「三条全宽横带」，改**前景大版（右下/下，重）→ 中景（中左）→ 远景（左上，轻）对角递进 + 套印错位**，上 1/3 留白做「天空/水面」；印章落对角线另一端做平衡。这是浮世绘名所绘的经典纵深 |
| **F1 浮光玻璃** | **中心聚焦 + 对角深度栈** | 深度栈沿「左上（远景/小/透）→ 右下（近景/大/实）」**对角线递减**，重心回到光学中心；标题放近景层，正文/数据沿对角分布；对角另一侧大留白 + 柔光斑做平衡。彻底告别「左柱堆叠 + 右半页死区」 |

> 一句话：**E6 = 网格 + Z 动线，G2 = 两栏，E7 = 对角线纵深，F1 = 对角深度栈**——四套骨架互不相同、且各自内部有严格秩序。

## 4. 落地方式（G10 契约升维）

在 `theme.md` 的 `G10 composition_program` 里**新增一个最高层字段 `page_composition`**，卡片级的 `signature_operator` 从属于它：

```
page_composition: {
  skeleton: "模块网格+Z动线" | "非对称两栏" | "对角线纵深" | "对角深度栈",
  grid:      { margin: 120, gutter: 40, columns: 12 },   // 统一模数
  balance:   { anchor: "标题块", counterweight: "印章/焦点" }, // 重心规则
  whitespace_ratio: "≥40%",                              // 负空间下限
  flow:      "Z型" | "左→右" | "对角" | "对角递减"          // 视觉动线
}
```

这样「卡片占比 / 间距 / 重叠」**第一次被一条总纲约束**，而不是每页拍坐标。DOM 结构测试也相应增加「网格吸附 / 重心象限 / 留白」三类断言。
