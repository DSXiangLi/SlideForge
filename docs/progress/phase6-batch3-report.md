### 灰度盲测预期

去色后四套主题的结构差异：
- **G4**：大面积黄色面 → 灰色面块 + 靛蓝结构线 → 海报式出血结构
- **G5**：三色反转面 → 三档灰度面并置 → 无描边色面跳跃
- **E2**：双线图框 + 标注线 + 网格纸 → 工程制图结构
- **E3**：中轴对称 + sunburst 放射线 + 菱形 → 仪式对称结构

四套在灰度下应可区分：G4 靠出血面+结构线，G5 靠三档灰面并置，E2 靠图框阵列+网格，E3 靠中轴对称+放射线。
