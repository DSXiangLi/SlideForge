## 3. 指纹（举证，不自动打回）

### 3.1 同内容 A/B（核心）——4 张完整内容页两两骨架相关

| 配对 | 相关 |
|---|---|
| e6 ↔ g2 | 0.356 |
| e6 ↔ f1 | 0.426 |
| e6 ↔ e7 | 0.499 |
| e7 ↔ f1 | 0.521 |
| e7 ↔ g2 | 0.676 |
| **f1 ↔ g2** | **0.841** |

均值 **0.553**，最高 0.841，>0.8 占比 16.7% —— **未达 G10 草案「类间 ≤0.35 / >0.8 占 0」的目标**。

### 3.2 关键结论（诚实）

**E6 成功分化**：与其它三套全 <0.5（0.36–0.50），因为孟菲斯积木是「大面积糖果色块」，灰度化后仍有明度结构。

**G2 / F1 / E7 三个浅底主题在完整高密度内容下趋同**（彼此 0.52–0.84）：
- 根因 1：三者都是「浅底 + 深字」世界（腮红粉 / 冷雾白 / 宣纸米），灰度化后底色明度差异极小；
- 根因 2：完整内容页信息密度高，主题算子的「留白 / 方向性」被内容占满，四套都退化成「左上标题 + 正文块 + 数据块」的两栏/三栏格局；
- 根因 3：`f1 ↔ g2` 最严重（0.84）——两者 full 页都是「左正文 + 右数据」两栏，结构几乎同构。

对照：已升级的 B1（IKB 满版）/ C3（暗底）/ E5（红力带）/ H1（竖排）四页类间 0.055，正是靠**大面积明度/方向差异**（深底、色带、竖排），而非文字排列。
