## 0. rev8 本轮做了什么（回应「都变对角线又一样」）

用户点破：光改「方向」（对角/中心/两栏）撑不起差异，因为方向只有几个取值，30 套必然撞。真正的差异载体是**明度签名（去色后墨水的空间分布）**。

| 主题 | 明度签名（去色后） | 方向/材质 |
|---|---|---|
| E6 孟菲斯 | 中等明度色块**散布** | 模块网格 |
| G2 荧光笔 | 浅纸底 + 左正文右索引**纹理** | 两栏 |
| **E7 浮世绘** | **浅纸 + 右下深墨前景面** | 对角线 + 木刻墨版 |
| **F1 玻璃** | **深底 + 居中亮玻璃** | 中心聚焦 + 暗色玻璃 |

两处核心改动（都顺着主题本色，不硬拗）：
- **E7**：前景大版改为深墨底 + 纸色字（浮世绘木刻「墨版」），与远景浅纸形成「浅纸深块」明度签名。
- **F1**：整页改暗色玻璃（深底 + 白色半透明亮玻璃），与 E7 的「浅纸深块」明度相反，且方向改中心聚焦（不与 E7 对角线撞）。

> 关键机制：指纹做了「极性归一」（暗底页反相），所以测的实质是**墨水空间分布**（深色内容在页面哪里集中），不是明暗极性本身。E7 墨水集中在右下、F1 集中在中、G2 分散左右、E6 散布——四套分布两两不同。
