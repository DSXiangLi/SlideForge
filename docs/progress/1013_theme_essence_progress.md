## 三、E6 孟菲斯 5 轮迭代经验（核心方法论沉淀）

| 版本 | 改动 | 发现的问题 | 学到的原理 |
|---|---|---|---|
| v1 | 从零生成（含旋转容器） | 字歪七扭八无法读 | 原理4: 倾斜容器破坏可读性 |
| v2 | 去旋转，色面块散布 | 零落散乱无布局引导 | 原理5: 布局传递信息，装置传递风格 |
| v3 | 有秩序排列，大小不等 | 并列信息大小不等造成认知混乱 | 原理1: 并列等大，主次不等 |
| v4 | 并列等大对齐 | 小色面在大画幅上显小气 | 原理3: 色面占满可用宽度 |
| v5 | 色面占满宽度 + 修复重叠 | 容器重叠 + JS null 引用 | 原理6: 尺寸由内容决定 + framework 修复 |

## 四、视觉原理总结（8 条，详见 learnings 文档）

1. **并列信息等大对齐，有主次信息大小不等**
2. **投影一致性 = 信息一致性**
3. **高对比色面块必须占满可用宽度**
4. **倾斜容器破坏信息可读性**
5. **布局传递信息，装置传递风格——两者叠加**
6. **色面块尺寸由内容决定，不由视觉随意性决定**
7. **同一布局换皮 ≠ 主题差异化**
8. **主题灵魂 = 视觉装置，不是配色方案**

## 五、下一步工作

### 优先级 1：G1/G2/G4 评估（慎之又慎）

**重要前提**：G1/G2/G4 在精准手术后效果其实还可以——用户明确表示"之前的效果还可以"。因此当前不确定 guizang 污染在这三主题中具体体现在哪里。

**在做任何改动之前，必须先回答以下问题**：
1. G1/G2/G4 当前 8 页中，哪些页面用户觉得效果不好？哪些页面效果是好的？
2. 具体的 guizang 痕迹（masthead/reveal/jc:center）在这三主题中是"污染"还是"兼容"？——G1 年鉴本身是编辑出版物，masthead/hairline 可能是兼容的；G2 手账和 G4 海报则可能不兼容
3. 从零重新生成是否会丢失当前已经好的部分？（E6 迭代中 v2/v3/v4 都曾改坏过原本好的部分）

**风险评估**：
- E6 五轮迭代的教训：每次"从零生成"都有改坏已有效果的风险
- G1 的配色和字体（Cormorant Garamond / 深翡翠 #1A3A2E / 金 #C9A227）在第二轮重建中被改坏过——这次绝不能再动
- G2 的 Caveat 手写体和荧光圈注也是容易被改坏的灵魂元素
- G4 的 Archivo 字体和琥珀金 #E8B81C 同样不能动

**决策原则**：
- **如果用户认为当前效果可以接受，不做从零重建**——只做精准修补
- **如果需要改进，先定位具体问题页和具体问题元素**——不做全局重建
- **每次改动后必须与用户确认**——不批量生成后才发现问题
- **保留原始配色/字体/母题**——只清理 guizang 骨架污染（已完成的精准手术可能已经足够）
