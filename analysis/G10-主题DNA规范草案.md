# G10 构图程序字段组 · 规范草案

> 目标：让主题从「一组可替换的参数」升级为「一段决定信息如何进入空间的程序」。
> 状态：草案，未写入技能库。配套实证见 `dna-soul.html` 与 `_fingerprint.py` / `_fingerprint.json`。

## 0. 一句话问题

项目的主题定义（G0–G9 + bake_brief）写得相当好，但**能定义身份的字段全部走在两条不进 HTML 产物的通道里**：

| 通道 | 内容 | 消费方 | 是否进 HTML |
|---|---|---|---|
| A | G0 世界参考 / unforgettable / 分化声明 | 选型面板与用户（`SKILL.md Step 2` 明说是「向用户解释主题气质的最好语言」） | 否 |
| B | bake_brief · layout_blueprints / 主导隐喻 / 标题重构 | `compile-bake-prompts.py`，仅 Step 5.6 整页烙入（`index.md §47`：「不进 HTML 产物」） | 否 |
| C | G1 色值 / G2 字体 / G3 质感 / G9 母题 CSS / G5 动效 | `SLOT: theme tokens` + `SLOT: theme css` | **是** |

C 通道是一组形容词（色、字、纹理、贴纸、缓动），而 `skeleton.html` 的 `SLOT: slides` 明确由生成侧逐页决定 DOM。**主题对「信息如何被摆进空间」没有任何主权**，于是 30 个主题共享同一副骨架。

制度层加剧了这一点：`sync-themes.mjs:41-43` 把「两个主题是否不同」实现为 `L1–L7 至少 3 层实质分化（规范化文本比较）`——只比 Markdown 字段，不渲染一帧。`components.md §11` 的六构图谱系有硬规则，但管的是 deck 级节奏，与主题身份无关。

### 本轮实测（`analysis/_fingerprint.py`，28 张 theme-sampler 样张）

| 指标 | 现状 28 张样张 | 4 张 G10 演示页 |
|---|---|---|
| 骨架层两两结构相关（强模糊后的块密度向量） | 均值 **0.459**，最高 0.990；23.3% 的配对 > 0.8 | 均值 **0.055**，最高 0.384；**0%** 的配对 > 0.8 |
| 皮肤层两两结构相关 | 0.299 | 0.040 |
| 与「平均脸」的结构相关 | 均值 0.569，最高 0.871 | — |
| 结构边缘主方向 | **28/28 全水平**，0 个垂直/对角 | 出现垂直主结构（H1 竖排） |
| 墨水重心 X / Y | 0.416 ± 0.087 / 0.455 ± 0.064 | 0.553 ± 0.074 / 0.512 ± 0.073 |

28 张样张灰度叠加后仍是一张清晰可读的 PPT（标题、正文、三格 KPI、项目符号、页脚位置逐一重合）；四张 G10 演示页叠加后是一团互相冲突的残影。

## 1. 新增字段组 G10（必填，硬约束）

写进每个 `themes/<分类>/<id>/theme.md`，紧跟 G9 之后、`bake_brief` 之前。

```yaml
G10 composition_program:
  doctrine:            # 一句话：这个主题替内容主张什么（不是"看起来怎样"）
  signature_operator:  # 一个动词短语；必须能改 DOM 结构，不能只改 CSS 外观
  silhouette:          # 主分割方向 / 块面形状 / 重心象限 / 最大留白矩形位置
  info_grammar:        # 页角色 → (内容单元 → DOM 结构) 映射，至少 cover/claim/analysis/data
  invariants:          # 3–5 条可机器验收的空间不变量
  forbidden_defaults:  # 本主题禁止落回的通用版式（列具体版式名）
  dna_events:          # 页角色 → 算子强度（强/中/弱/无），全 deck 的节奏表
```

### 字段纪律

1. **`signature_operator` 必须是动词 + 受力对象 + 覆盖范围，且必须通过「DOM 结构测试」**：写完后自问「如果把这条算子删掉，页面的元素数量、分组、顺序、位置会不会变？」答「不会，只是颜色/装饰变了」即不合格，退回重写。
   - 反例（现状 unforgettable）：`加号角标 + 网格点阵`、`闪烁光标块`、`朱砂印章` —— 都是可贴在任何版式上的贴纸。
   - 正例：`把整页压进 12 栏网格，标题跨栏语义断行，其余信息沿栏吸附；唯一焦点是一次对齐误差为零的偏移`。
2. **灵魂必须承载信息**。标志性形状要升级为信息容器：E5 的对角带装标题、C3 的 ASCII 框装证据、B1 的网格线是数据坐标、H1 的题跋列装论点。`index.md §73` 现在规定「母题件在产物中是装饰，一律 `data-editable-skip`」——需拆成两类：
   - **签名结构件**：形状由 CSS 承担（`data-editable-skip`），但其内部承载的文字仍是 `data-editable` 叶子节点；
   - **纯装饰件**：维持现状。
   文字始终留在 DOM，不牺牲可编辑性，也不需要整页生图。
3. **`invariants` 至少 1 条必须是几何/方向性的**（主轴角度、重心象限、留白矩形面积、块面 bounding box），不能全写成颜色/字号/透明度。每条要能在渲染后的 DOM 或像素上测出来，格式建议 `指标 运算符 阈值 @ 页角色`。
4. **`dna_events` 是身份的一部分**。身份靠节奏被感知，不靠每页重复贴同一个母题——每页同强度出现只会让签名退化成壁纸。
5. **单一信息源**：`bake_brief.layout_blueprints` 与 `G10.info_grammar` 必须合并（建议 G10 为主，`layout_blueprints` 从 G10 派生），让纯 HTML 产物与烙入生图共用同一份构图契约。这是 A/B/C 三条通道分裂的根治办法。

## 2. 四个试点主题的完整 G10（可直接抄进 theme.md）

### B1 瑞士国际主义

```yaml

signature_operator: 把整页压进 12 栏网格（栏界以 hairline 可见化），标题跨栏语义断行并倒挂字重，
  其余信息沿栏吸附；把横向等权 KPI 重排成右侧纵向数据脊，只给一个数字一次 accent 面积事件。
silhouette: 横竖双轴；矩形分区；重心左上象限；右上 ≥25% 主动负空间。
info_grammar:
  cover:    ≤4 文本元素；满版 IKB + 反白发丝巨字
  claim:    左 7 栏巨字（200 字重、语义断行）+ 右 5 栏数据脊

  - 主轴 ∈ {0°, 90°}，斜向结构件面积 = 0

  - accent 实色面积 3–10%，且单页仅一处

forbidden_defaults: [三格等权 KPI, 居中 hero, 通栏长正文行 >70cqw, 卡片墙, 任何渐变]
dna_events: {cover: 强, claim: 强, analysis: 中, data: 强, divider: 中, closing: 中}
```

## 3. 生成侧流程改动

### Step 2 · 冻结主题

现在只冻结「token + 变体 + G9 CSS」。改为同时冻结 **G10 程序**：把 `signature_operator` / `info_grammar` / `invariants` / `forbidden_defaults` / `dna_events` 写进本 deck 的页计划表头，作为整个 deck 的构图契约。「主题只选不改」不冲突，反而强化——程序是策展预设，生成侧只能执行，不能即兴。

### Step 1 · 页计划表

新增两列（沿用上一轮「呈现发散」的思路，但把发散锚定到主题算子）：

| 页 | 叙事角色 | 一句话 | 内容清单 | 明/暗 | **算子强度 + 本页视觉论点** | **被否掉的两案及原因** |
|---|---|---|---|---|---|---|

`算子强度` 必须取自该主题 `dna_events`，不得逐页随意；偏离要在「被否掉的两案」里写明理由。

### Step 4 · 逐页生成

- 每页动手前先读 **本页算子强度**，再读 token；顺序反过来会退回到「先排内容再刷皮」。
- `forbidden_defaults` 是硬规则：命中即返工，不是建议。
- 构图决策层分工改写为：**内容决定「讲什么」，主题决定「信息如何进入空间」**。二者不互相覆盖。
- G8「亲和/禁忌」（原为可选召回清单）升级为 G10 的硬约束来源；`components.md §11` 六谱系仍管 deck 级节奏（连续 3 页同谱系违规），但**谱系选择必须落在该主题 `silhouette` 允许的方向集合内**。

### Step 5 · 新增门禁

保留全部 55 项负向约束（不溢出、不重叠、≥18px），另加一组正向审美门禁。两者叠加，不互替。

## 4. 指纹向量与盲测门禁（`check-dna.py` 设计）

### 输入

每主题按 G10 渲染 3 页（cover / claim / data），或直接从交付 deck 取页。

### 低频指纹向量（机器可测的「一眼」）

| 维度 | 测量方式 |
|---|---|
| 主轴方向直方图 | 强模糊后的梯度方向分箱（横 / 竖 / ±对角 / 放射），见 `_fingerprint.py` 的 `edge_struct` |
| 墨水重心与离散度 | 极性归一后的加权质心 |
| 最大留白矩形 | 面积 + 象限 |
| 大面积实色块 | bounding box + 形状（矩形 / 三角 / 楔形 / 圆） |
| 尺度落差 | 最大/最小字号比（DOM 计算样式读，比像素稳） |
| 重复周期 | 网格 / 扫描线 / 分栏周期（自相关峰） |
| 色面积向量 | accent / ink / paper 占比 |
| 低频块密度 | 强模糊后 10×6 块均值 z-score（本轮 `s` 向量） |

### 判据（阈值建议，用本轮实测校准）

1. **类间距离**：任意两主题的骨架层两两结构相关 **≤ 0.35**（现状均值 0.459；G10 演示页 0.055）。> 0.8 的配对占比必须为 **0**。
2. **类内一致性**：同主题跨页骨架相关落在 **0.55–0.85** 区间。过高 = 每页复制同一个版式（身份退化成壁纸）；过低 = 主题失控。
3. **节奏方差**：`dna_events` 声明的强/弱形态必须能在指纹上测出差异（强形态页的 signature 几何指标显著高于弱形态页），否则 `dna_events` 视为未执行。
4. **几何不变量**：逐条核 `invariants`，任一不满足即失败，指名具体页与具体指标。
5. **盲测分类**：把页灰度化 + 缩到 240×135 + 去掉主题名，交给人或 VLM 做 30 类分类；准确率低于阈值即判「DNA 不可辨」。这是唯一直接对应「一眼看出」的判据，前四条是它的机器代理。

### 输出

```
theme-pair: e5 ↔ b1   skeleton_corr=0.61  FAIL (>0.35)
  → 指名撞脸主题，而不是笼统报「分化不足」
page: slide-04        invariant[主轴 ∈ {0°,90°}] 实测 12°  FAIL
theme: h1             类内相关=0.93  WARN (每页复制同一版式)
```

### 与现有校验器的关系

`sync-themes.mjs` 的文本分化校验**保留**，但改名为「元数据分化」；新增 `check-dna.py` 负责「像素分化」。二者并存，互不替代。校验器增 G10 schema 必填检查（含「DOM 结构测试」的人工签署字段，机器无法自动判定动词是否真能改结构）。

## 5. 与现有架构的冲突清单（逐条给处理）

| 现有规则 | 冲突 | 处理 |
|---|---|---|
| 主题「只选不改」 | 看起来像增加了自由度 | 不冲突：G10 是策展预设的一部分，生成侧只能执行不能即兴；自由度反而更小 |
| 「构图由内容决定」「token 层枚举、版式层自由」 | 主题要管构图 | 改写为「内容决定信息，主题决定信息如何进入空间」；版式层仍自由，但自由在**主题允许的 silhouette 集合内** |
| 骨架逐字复制 | 需要新增结构 | 不改框架层 CSS/JS，只改 `SLOT: slides` 的 DOM 结构与 `SLOT: theme css` 的签名结构件规则 |
| G9「母题件是装饰，一律 skip」 | 签名件要装文字 | 拆两类：签名结构件（形状 skip、内部文字可编辑）与纯装饰件（维持现状） |
| bake_brief「不进 HTML 产物」 | 蓝图应与 HTML 共用 | G10 为单一信息源，`layout_blueprints` 由 G10 派生；HTML 与烙入生图共用构图契约 |
| 55 项负向门禁 | 缺正向审美判据 | 全部保留，另叠加正向门禁；工程可靠性是底座，不是天花板 |
| 文字 DOM 可编辑 / 禁整页生图（默认） | 担心表现力不够 | 本轮四张反证全部用活文字 + CSS 完成，无生图、无烙入 |

## 6. 迁移路线

1. **试点（4 个）**：B1 / E5 / C3 / H1 —— 世界观差异最大，已在本轮给出完整 G10 与视觉反证。做成 3–5 页真实 deck 样张，跑盲测。
2. **打通链路**：G10 → 页计划表 → DOM 编译 → 渲染门禁；同时让 `layout_blueprints` 从 G10 派生。
3. **补校验器**：`check-dna.py` + `sync-themes.mjs` 的 G10 schema 检查 + 页计划表新列。
4. **铺量 30 个主题**：按「世界参考 → 签名算子 → invariants」逐主题补写。分组顺序建议：先空间/线法类（E2 蓝图、E4 包豪斯、E8 号外、E11 票据、A1 电子杂志），再质感/光线类（C4 纸与墨、E9 地质地层、F1 浮光玻璃、D2 柔光暗房），最后色法/字法类。
5. **合并规则**：凡写不出 `signature_operator`（答不出 DOM 结构测试）的主题，说明它其实只是某个主题的配色变体——按 `index.md` 的变体规则合并，而不是硬凑一条算子。主题数量下降不是损失，身份清晰度上升才是收益。

## 7. 验收口径

> 一页幻灯片有灵魂 = 遮住主题名、去掉颜色、缩到缩略图之后，观众仍能把它归回它的世界；并且能说出这个主题替内容主张了什么。

这句话拆成三条可验收项：**类间可分**（盲测分类）、**类内成族**（跨页一致但有节奏）、**主张可读**（视觉论点先于文字被接收）。现有 55 项验收一条都没覆盖这三条——这正是「满分过闸却像排版过的 Word」的原因。
