01 / DEF

我说的「审美巅峰」是什么

先把它变成可证伪的判据，避免我们各说各的「高级感」。这不是玄学，是八条可以逐页打分的轴——而且它们是相乘关系：任何一条接近 0，整页就塌回文档。

一页幻灯片不是「把内容排好看」，而是用一个不可转述的视觉决定，让观众在读到文字之前就接收到论点。

人类顶级幻灯片（Müller-Brockmann 的海报、Pentagram 的品牌册、Apple keynote、日本展陈图录）之所以被记住，不是因为配色准、字体对、留白够，而是因为每一页都有一个只有这一页成立的视觉构造：一个尺度极端、一次出血的裁切、一块反常的负空间、一种真实的材料。信息只是搭在这套构造上的乘客。

当前项目优化的是「信息如何安全、一致、可编辑地落到画布上」。这是工程问题，而且解得很好。审美问题问的是「这一页凭什么值得被看」。两者不在同一层，所以把主题从 29 套加到 59 套，天花板不会动。

02 / LOGIC

当前设计思路：它其实在优化另一件事

把 SKILL.md、themes/index.md、typography.md、components.md 拆开看，整个体系是一条非常清晰的「约束链」，五层里前三层做得很扎实，缺的是后两层。

LAYER 1 · 已具备 / 很强

决策前置

主题只选不改、密度双档冻结、页计划表先于代码、呈现发散三案。用策展库对抗 AI 收敛到「紫蓝渐变＋卡片墙」。诊断：这是反平庸的，不是制造卓越的——它能挡住最差解，够不到最优解。

LAYER 2 · 已具备 / 很强

Token 系统

G0–G9 七层表达力栈：色彩、字排、质感、容器、动效、构图亲和、装饰母题；主题两两分化 ≥3 层。诊断：这是极高质量的风格词汇表，但词汇表只保证不串味，不保证造句漂亮。

LAYER 3 · 已具备 / 极强

数学门禁

容量预算 → Playwright 实测 → PPT 度量预认证 → 导出重开认证。零溢出、零重叠、字号下限、字体子集内嵌。诊断：55 项验收全部是负向约束，没有任何一项测量对比度、重心、留白形状、网格吸附、节奏。

LAYER 4 · 缺失

美术指导 / 构图语法

components.md §11 已经写出六谱系（宣言 / 数据英雄 / 网格矩阵 / 轴与节点 / 图文证据 / 裂屏对开），但它是召回清单不是生成约束：没有"这页必须选哪个谱系、为什么"的强制决策，也没有可测量的验收。于是实际产物稳定回落到最省事的那个谱系。

LAYER 5 · 缺失

审美验收

没有「实现的字号对比 ≥ 规范声明」「单一视觉重心的面积占比」「元素对栅格的吸附误差」「装饰母题的可辨识度」「连续 N 页的节奏方差」这类正向指标。结果：所有主题都能通过验收，也都不够好。

结构性代价

约束的合力方向

固定 1920×1080、正文 ≥18px、文字必须在 DOM 可编辑、图片只走槽位、系统字体栈、禁止响应式、所有元素不许相碰——每一条单独看都对，合起来把解空间压向「安全边距内的整齐文本块」。天花板是被可靠性设计出来的。

  • EVIDENCE A28 张样张 = 1 个版式 × 28 张皮标题、两段正文、三格数字、三条 bullet、页脚，位置几乎完全重合。README 写「主题之间是排版、材质与图形语言的系统差异」，实际主要差异在色板与几个角标。
  • EVIDENCE B规范写了，产物没执行B1 的 G2 要求主标题:正文 ≥8:1、巨字字重 200–300；bake_brief 明写「禁居中对称」「单一 accent 焦点」「封面至多 4 个文本元素」。而 p02-b1 实测对比约 4.5:1、字重约 400、重心居中偏上、accent 只是一个 2.7% 宽的小方块。
  • EVIDENCE C"unforgettable" 写在文档里，没写在页面上每个主题都有 unforgettable 字段（B1 是「加号角标＋网格点阵」），但角标是 14px / opacity .55 的四角细十字，投影后基本看不见。签名成了元数据，不是视觉事件。
03 / B1

选 B1 瑞士国际主义，因为它是唯一能自证的样本

不用换主题库、不用联网字体、不用生图、不用烙入——只用现有 token 和纯文字，就能把「巅峰」做出来。如果这样都做得到，说明差距不是工具限制，是决策限制。

REASON 01

参照物没有争议

它的「世界参考」写的就是 1960s Müller-Brockmann 海报＋瑞士铁路 signage。这是平面设计史上被公认的巅峰样本，不需要我先说服你某种风格好看。

REASON 02

规范已经把答案写好了

b1/theme.md 的 bake_brief 里逐条写着：倒挂字重、≥8:1、语义断行左对齐、网格对齐即装饰、单一焦点、禁居中对称、封面 ≤4 文本元素。不是在发明新方向，是把项目自己写的东西落到页面上。

REASON 03

纯 CSS 可达，不与工程约束冲突

瑞士风的全部语言是：巨字、栅格、hairline、实地色块、负空间。全部是活文字＋纯色，可编辑、可导出、不溢出。这一页能同时满足 55 项门禁和审美巅峰。

① 标题
巨字没有巨到成为图形

② 段落
满宽长行＝文档，不是版面

06 / SYNC

先对齐，再动手

这一页是诊断稿，没有改任何 theme.md / 骨架 / 脚本。在动主题库之前，需要你确认我们对「巅峰」的定义是不是同一件事。

  • 顺手发现 ① 文档漂移：README 写「29 套主题」，index.md 分类表合计 30，磁盘上 theme.md 恰好 30 个；`assets/theme-sampler/` 只有 28 张（缺 p27）。规格、文档、产物三处对不上，本身也是「规范没被验收」的缩影。
  • 顺手发现 ② 默认值与主题立场相反：`skeleton.html` 的默认示例 h1 是 `font-size:120px; font-weight:700`，而 B1 / 瑞士系声明巨字必须 200–300 细体、倒挂字重。生成侧拿骨架起步时，第一眼看到的是反例。
  • 顺手发现 ③ 主题文件残段：`references/themes/line/b1/theme.md` 末尾挂着「## C 系 · 深色与个性（源自 frontend-slides）」，与 B1 无关，疑似早期合集复制残留。
