## 布局契约

各主题的布局由 `theme.md` 的 G10 `composition_program` → `info_grammar.claim` 契约决定：

- **G4 靛墨黄页**：海报式不对称出血——黄楔右缘出血 + 展览编号签 + 页底双色对撞带 + 余烬橙单点
- **G5 三色旬刊**：三色反转配对面——刊号签页眉 + 双线刊框 + 三色反转配对卡阵 + 页底三色带
- **E2 蓝图**：双线图框阵列+标注线——制图网格纸全页 + 双线图框 + 图框标题栏 + 尺寸标注线
- **E3 装饰艺术**：中轴对称金线放射——扇形放射 + 双线金框整页 + 菱形分隔 ×2
