# 烙入生图指令参考（bake-prompts）

> 读者：执行 Step 5.6 页面烙入 pass 的 AI coding agent。
> 分工：脚本 `compile-bake-prompts.py` 管确定性骨架（Canvas/Text/Constraints 段逐字防幻觉）；**你管 Layout 段与风格段的写法**——本文档是这部分的查询库。不同构图谱系对生图模型的指令策略不同，照谱系查。

> **烙入语义（2026-10-07 用户裁决，v3 升维转向；10-08 v4 收紧）**：烙入 = **内容忠实 + 视觉升维**，不是保真封存。生图的任务是把扁平 HTML 页升维为图像级作品——插画化、布局重构、文字视觉化改造、材质/光影/纵深/肌理全面超越原 HTML；"因为有参考图所以内容要参考，但效果要更好"。保真封存需求由保真导出轨（HTML→PPTX 的 PDF/SVG 轨）承担，烙入不再追求"和 HTML 看起来一样"——**与参考图趋同视为失败**。v4 收紧（用户目检 D 组裁决：候选受参考图影响仍太大）：参考图角色六字诀——**只内容与配色**（①文字内容与信息层级 ②配色基调，其余一律不参照）；编译器内置「升维手段」六维工具箱（光线/质感/插画/布局/容器/字体，每维都要可见地超越参考图）。三条推论不变：① 参考图是内容锚，不是视觉目标；② 蓝图约束信息结构，不构成构图复刻纪律；③ 文字逐字不变，但标题按 `typography_bake` 做视觉化改造，不是贴在画面上的字。

## 0. 四条总原则

1. **生图模型不是排版引擎**。它擅长氛围、材质、光影、构图感，不擅长精确排版与大量文字。Layout 段的职责是**把版式翻译成画面描述**（三分区、视线流、留白位置），不是复述 HTML 结构。
2. **文字越少越准**。每个要渲染的字都是错字风险敞口。烙入页的理想文字量 = 大标题 + 一行副题 + 一行标注。正文密布的页不该烙入（那是 HTML 页或插画槽位的职责——入口选页时就该挡掉；实测上限参考：2026-10-08 高密度压力测试，905 字符/41 行即出现长句系统性截断，standard/advanced 两档同症）。
3. **定量图表页禁整页烙入**（2026-10-08 三场景实验实证）：带真实数值比例的图表（柱/瀑布/折线等）在生图中数据失真三线齐发——副题数字错（194→184）、减号丢失（−38→38，符号语义反转）、柱高比例误差 10–26%。数据图表留在 HTML 层；要升维只烙不含定量数据的页面，或图表区留空后置合成。**例外**：图表仅作氛围装饰、数值不参与阅读的非数据页不在此列（那是插画语义）。
4. **参考图是内容锚，不是风格目标**（v3；v4 收紧为"只内容与配色"）。HTML 页截图只提供两样东西：① 文字内容与信息层级；② 配色基调——光线/质感/插画/布局/容器/字体全部由「升维手段」六维工具箱重新设计（编译器 v4 起内置该节，回退路径同）。"匹配参考图质感"类措辞在 i2i 场景是最高权重指令，会把产物压成参考图复刻，禁止。无参考图臂（`--anchor none`）是合法实验路径：色彩锚定完全交给 Global Style 的 token 与简报，色彩脱锚风险由 check-image-harmony 后置把关。

## 1. 按构图谱系的指令策略

谱系定义见 `components.md` §11；此处给每系的 Layout 段写法与特有雷区。

### 巨字宣言（封面/章节仪式页的主力）

- **写法**：明确"标题即画面主体"——给字号层级感受（超大/占画面三分之一）、字重气质（衬线庄重/黑体力量）、位置（上三分之一/左对齐/居中），背景描述从简（纯色/微质感/低饱和氛围图），让标题独占注意力。
- **雷区**：背景喧宾夺主吃掉标题可读性 → 显式写"标题区背景保持干净低对比"；长标题必断行说明（"标题分两行：『×××』/『×××』"）——断行位置是构图决策，不交给模型。

### 数据英雄（大数字页）

- **写法**：数字是主角——"巨大数字『42.8%』占据视觉中心，字重极粗，数字必须逐字精确"；辅助说明文字降级为小字标注层感受。
- **雷区**：数字与符号是乱码高发区（%、小数点、千分位）→ 数字个数压到最少（一页一个英雄数字），并在 Constraints 已有"逐字"之上，在 Layout 里单独点名复述一遍关键数字。

### 网格矩阵（卡片/多宫格）

- **写法**：给网格秩序感（"3×2 等距卡片网格、细 hairline 分隔、严格对齐"），卡片内内容只描述类型（图标位/标题位/一行说明位），不逐格写文字——格内文字进 Text 段逐字给。
- **雷区**：模型爱给卡片加随机装饰与阴影 → 显式写"扁平、无阴影、无拟物质感"（除非主题 G4/G9 另有声明）；格数必须写死，否则模型自行增减。

### 轴与节点（流程/时间线）

- **写法**：方向是第一信息（"横向中轴，4 个节点从左到右，箭头指示流向"）；节点造型一句话（圆点/方碑/里程碑），标签位置（轴上方/下方交替）。
- **雷区**：节点数量漂移 → 数量写死 + "不多不少"；连接线样式（直线/曲线/虚线）显式声明。

### 图文证据（左图右文/上图下文）

- **写法**：分区比例写清（"左 45% 画面为摄影感场景图，右 55% 留白区排文字"）；图像区的内容描述走插画 intent 的写法（场景、视角、色调），文字区描述为"干净的留白底上排标题与要点"。
- **雷区**：模型把文字画进图里或把图压扁 → "图像区与文字区边界清晰，文字不压图"。

### 裂屏对开（对比/二元）

- **写法**：中缝位置与对比关系（"垂直中缝对半分，左冷右暖，两侧各一个大词"）；对比轴（明暗/冷暖/疏密）明说。
- **雷区**：两侧文字量不均导致模型自由发挥 → 两侧各自文字分别写清，并声明"两侧构图镜像平衡"。

## 2. 风格段的写法

Global Style 的确定性骨架由脚本拼装：**主题有 `bake_brief`（风格圣经）时，整段结构化简报由脚本原样注入**（见 §6），你不再手写气质散文——要写风格内容就回 theme.md 改简报（单源纪律）。主题无简报时（回退路径），脚本拼装 token 色值，你补的是**气质与材质语言**（经 `--style` / plan 输入）：

- 主题声明了 G7：逐字遵守其风格描述与禁忌；
- 未声明：缺省推导 = 主题色抽象图形的精细化版本。给材质词（纸张颗粒/墨韵晕染/扁平色块/霓虹辉光——与主题 G3 质感立场一致）、光词（柔和平光/戏剧性侧光/屏幕自发光）、时代感词（瑞士国际主义/装饰艺术/浮世绘——与主题世界参考一致）；
- 明暗：与页面明暗（dark 变体）一致，色值以 token 为准，不要再发明新色。

## 3. 失败模式与对策（回归校验时的判读）

| 症状 | 根因 | 对策 |
|---|---|---|
| 中文错字/乱码 | 文字太多或太小 | 减字（与上游协商砍文案）→ 重 roll；仍失败则诚实回退 HTML 页 |
| 数字/标点错 | 高发区 | Layout 中单独点名复述；连续两次错 → 回退，不硬磕 |
| 构图跑版 | Layout 写了 HTML 结构而非画面 | 改写为分区/视线流语言后重 roll |
| 风格与全 deck 脱节 | 锚图没起作用 | 换 `--advance-model`（advanced 档，参考图一致性更强）重 roll；检查风格段是否与锚图打架 |
| 水印/页码/画框 | 模型惯性 | Constraints 已禁；仍出现则重 roll |

重 roll 纪律：同一页至多 2–3 次重试（换表述/换模型档），不过即**诚实回退为 HTML 页**（Step 5.6 反降级硬规则）——HTML 页本身就是合格交付。

## 4. 与插画模式（Step 5.5）的指令差异

插画槽位是**页面里的一个矩形区域**：指令聚焦槽位内容本身 + 比例 + 与邻近文字的气质协调。烙入是**整页即图**：指令必须额外承担版式（分区、文字位置、留白）与页面级氛围——本文档 §1 的谱系策略只适用于烙入，插画槽位不要写版式指令。

## 5. 生图评审 rubric（择优与重 roll 的标尺）

§3 的失败模式对策覆盖"坏了怎么办"；本节是"多张里哪张好 / 这张够不够好"的评审标尺。每张生成图（含插画槽位图与烙入整页图）按六维评审，每维 0/1 + 一句话理由：

| # | 维度 | 判定标准 | 性质 |
|---|---|---|---|
| 1 | 文字逐字渲染正确 | 图中所有文字与 Text 段逐字一致——错字、乱码、漏字、多字任一出现即 0 | **一票否决**：此维 0 则整图不可用，不论其余维度得分 |
| 2 | 构图符合 Layout 节角色纪律 | 信息位置/数量/层级与角色蓝图一致（谱系见 §1；蓝图是结构纪律不是复刻纪律，构图重设计不扣分） | 计分 |
| 3 | 色彩在场 | 与 G2 呼应：`check-image-harmony.py` 报告为准——主色板锚定主题 token（指标 A 无锚率未触发）且 `--accent` 有呼应色（指标 B 未触发）；告警但确认是合法艺术化偏离（压暗/叠色）时可给 1，理由必须写明告警内容 | 计分 |
| 4 | 风格段气质匹配 | 材质、光感、时代感与风格段（visual_direction）一致，与 deck 其余页有家族相似性 | 计分 |
| 5 | 无不许可元素 | 无页码、水印、画框、出血等 Constraints 禁止项 | 计分（出现即 0，通常伴随重 roll） |
| 6 | 视觉升维（v3） | 产物在材质/光影/纵深/肌理上**可见地超越**扁平网页截图（简报 uplift 路径被执行）；**与参考图趋同、像一张 HTML 截图的，此维 0** | 计分（无机器裁判，目检执行；整页烙入图此维 0 视同未达烙入目的，按 reject 处理） |

**择优纪律**（成本决策已由用户批准 2026-10-06）：代表页（审批闸门页）默认 `--n 2` 双候选，agent 按 rubric 择优（维度 1 不过直接淘汰；同分取先）后才提交用户审批；批量页 `--n 1`，任一票否决项失败才按 §3 重 roll 纪律重试（至多 2–3 次，不过即诚实回退）。

**落账**：rubric 结论经 `imagegen-adapter.py --rubric-json <文件>` 透传进 `imagegen-ledger.json` 对应条目的 `rubric` 字段（adapter 只透传不解释），交付说明可追溯。记录格式：

```json
{
  "rubric_version": 1,
  "dimensions": {
    "text_exact":   {"score": 1, "reason": "标题七字与 Text 段逐字一致"},
    "layout":       {"score": 1, "reason": "巨字位于上三分之一留白区，符合巨字宣言谱系"},
    "color":        {"score": 1, "reason": "check-image-harmony 无告警"},
    "style":        {"score": 0, "reason": "出现照片质感，风格段要求扁平色块"},
    "no_forbidden": {"score": 1, "reason": "无页码水印画框"},
    "uplift":       {"score": 0, "reason": "产物与参考图趋同，漆面纵深/金属刻痕均未出现——未升维"}
  },
  "decision": "reject",
  "note": "风格不匹配，换表述重 roll"
}
```

`decision` 取值：`accept`（择优入选/可提交审批）/ `reject`（重 roll）/ `fallback`（重 roll 用尽，诚实回退 HTML 页或保持 placeholder）。

## 6. 风格圣经与页角色（D1–D3，2026-10-07 试点）

设计依据：指令的内容层从"散文"升级为"风格圣经"——主题的 bake 风格简报（`bake_brief` 字段组）驻留在 `themes/index.md`（单源），编译器负责确定性注入。本节是你在新体系下的写作规则。

### 6.1 页角色 → 蓝图选用规则

每页先定角色再写 Layout。角色来源优先级（编译器同一套规则，写进指令 Layout 节首行）：

1. plan.json 该页 `role` 字段显式声明（cover / divider / key-message / analysis / closing）；
2. slide id 关键词推断：`cover|title|首页|封面` → cover；`divider|section|chapter|part|toc|agenda|目录|章节` → divider；`closing|end|thanks|finale|封底|结尾|致谢` → closing；
3. 文本量推断：该页 texts ≤5 条 → key-message；>5 条 → analysis。

蓝图选用：主题简报有该角色的 `layout_blueprints` → 编译器注入该蓝图（位置×数量×标签），**你写的 Layout 段是在蓝图上细化内容，不是推翻蓝图**；角色无对应蓝图时按 `closing → key-message → 首个蓝图` 回落；主题无简报时回到 §1 六构图谱系自由写。蓝图抽象的是结构不是文案——同一主题不同页共用蓝图，内容差异由你的 Layout 段承担。

### 6.2 标题重构词汇表（封面/章节/关键观点页的一等技法）

主标题不是"打出来"而是"设计出来"。写 Layout 段时从主题简报的 `typography_bake` 取该主题定制词汇；通用词汇轴（选适合主题气质的，不是全用）：

- **细线结构笔划**：标题以骨架线稿呈现，笔划即结构；
- **半空心**：描边字与实心字混排，制造残影/层次（A1 Ghost 的原生语言）；
- **断笔**：笔划中段断开，断口嵌入主题元素（金线/扫描线/hairline）；
- **延笔**：撇捺末端延伸为装饰线，汇入页面主导母题（射线/sidebar 引线）；
- **隐喻融字**：主导隐喻进入字面结构——负空间成形（漏斗/扇形）、笔划成路径、字身成容器；**字面完整可读是不可让渡的底线**。

### 6.3 每页恰一个主导隐喻

motifs.md 八类隐喻（对比/增长变化/流程/数字呈现/层级/组成/因果/时间）进烙入指令的桥：关键页先从 motifs.md 选定**一个**主导隐喻（与该页内容关系忠实对应），然后在 Layout 段用一句话说明它**落在哪**——融入标题字型（§6.2 隐喻融字）、或成为画面唯一的核心图形结构。禁多隐喻堆叠；禁隐喻与文字内容脱节（rubric 维度 2/4 的判读依据）。

### 6.4 词预算（防 tag-soup）

- 风格内容：以简报注入为准，不另加散文；无简报回退路径的 `--style` 散文 80–120 词封顶；
- Layout 段 ≤150 词：分区/视线流/留白位置 + 角色蓝图上的内容细化，不复述蓝图本身、不复述 Text 段文字；
- 全文禁关键词罗列（tag-soup）——每个词必须承担构图/风格/禁忌之一的明确职责。

### 6.5 布局重构授权（restructure，v5；2026-10-08 实验实证成立）

**适用条件**（三个都要满足才开 `restructure: true`）：

1. **中低密度**：页文本量 ≤500 字符（高密度页的长句逐字渲染瓶颈已实证，重构会放大丢句风险）；
2. **平铺文本页**：内容是纯段落散文、无结构化组件（无卡片/图表/时间轴——已有结构的页用一般升维即可）；
3. **内容有关系类型可言**：motifs.md 八类里找得到对应（流程/对比/层级/循环/矩阵/时间轴……），纯叙述无结构的页重构不出信息图。

纪律：

- 重构的三条硬约束写死在授权段里（全部文字逐字保留 / 信息层级不变 / 配色基调不变）——重构的是呈现结构，不是内容；
- restructure 替代一般构图授权（"不要复刻参考图版式"的措辞升级为显式的重构授权），蓝图仍注入（信息结构纪律保留）；
- 验证判据：重构发生（段落形态消失、结构化元素出现）+ 信息完整（OCR 全行比对不丢行）——缺一即 reject，rubric 第七维"布局重构"记账；
- 失败模式：模型只给段落加卡片边框（伪重构）——授权段无效时加强负向措辞（"禁止保留段落平铺形态"）重 roll，一次不过即回退一般升维。

### 6.6 装饰升维授权（decorate，v5；2026-10-08 H 组实证成立）

**适用**：高密度内容页（超出重构/常规烙入的文字量上限）——内容区块与全部文字保持原位原样，只升维氛围：布局节奏微调、底部与边缘主题插画背景带、母题角饰/分隔线、光线与质感作用于背景与容器表面。授权段由编译器注入（plan 页级 `decorate: true`），含"文字区背景必须保持可读对比度"硬约束。

纪律：

- 与 restructure 互斥（restructure 优先）；两者都替代一般构图授权行；
- 验证判据：装饰只出现在非文字区（边缘/底带密度对比中部文字区）+ 文字可读性不劣化（OCR 同 band）；
- H 组实测（905 字符页）：装饰克制（底带/右缘密度 13–15% vs 中部 13%）、文字区对比度保持、harmony 零告警。

### 6.7 图表页数据强锚定（G 组实验结论：文字可锚定，几何不可锚定）

定量图表页若必须烙入，Layout 段必须把**每个数据点的数值与相对比例逐字写出**（"七柱：120 → +86 → +42 → −38 → −25 → +9 → 194；柱高与数值严格成正比，以 194 为满高：62%/44%/22%/20%/13%/5%；减益柱带减号、向下悬浮"），Constraints 加「图表数据点数值逐字、柱高/扇形角度与数值成正比、坐标轴刻度不失真」。

**G 组实测结论（维持 §0 禁烙纪律）**：强锚定后文字层全部收敛（数值 120/+86/+42/+9/194 全对、副题"从 120 到 194"修复、减号在场），但**几何层不收敛**（柱高误差最大 −31%，超 10% 阈）——生图模型可以被指令锚定数值文本，锚不定像素比例。§0 第 3 条"定量图表页禁整页烙入"维持不变。
